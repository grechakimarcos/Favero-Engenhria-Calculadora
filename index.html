Integração com IA (Em Desenvolvimento)

O sistema já está estruturado para aprender com os projetos anteriores. Cada projeto salvo gera um registro com as características técnicas e o resultado real. Quando a API de IA for integrada (App.Config.AI_ENDPOINT), o sistema poderá estimar automaticamente as horas necessárias para novos projetos com base no histórico.

Registre as horas realizadas na tabela acima ao concluir cada projeto para alimentar o modelo de aprendizado.
